# BSE-METISSE

[Public version](https://astronomy.swin.edu.au/~jhurley/bsedload.html) of BSE with a few updates, modified to be compatible with both SSE and METISSE. METISSE is available at https://github.com/TeamMETISSE/METISSE. The documentation for METISSE is avilable at this [link](https://metisse.readthedocs.io). 

Refer to the section on [BSE](https://metisse.readthedocs.io/en/latest/usage_other.html#bse) for how to install and use this version of BSE with METISSE.

For more details see: [Agrawal et al 2023](https://arxiv.org/abs/2303.10187) and [Agrawal et al 2020](https://arxiv.org/abs/2005.13177).
